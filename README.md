# Testimonial Cards

A small, responsive UI example showcasing testimonial cards built with semantic HTML and modern CSS. This repository contains a minimal, self-contained demo you can open in the browser to preview different card styles: callout, bordered, dark theme, and avatar groupings.

## Purpose
 - Demonstrate layout and positioning techniques using CSS (flexbox, spacing, card composition).
 - Provide a compact component you can adapt for documentation sites, portfolios, or landing pages.

## Files
 - `index.html` — Demo page with several testimonial card examples.
 - `style.css` — Styles for the cards and responsive layout.

## How to view
1. Open `index.html` in your browser (double-click or use a local static server).
